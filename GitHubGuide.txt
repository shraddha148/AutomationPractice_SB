################################### Resolve Merge Conflict ######################################

Merge Conflict Scenarios.
1. In main branch filename: greeting.txt
   content: good morning

2. Person1 : branch
   filename: greeting.txt
   content: Person1: good morning, How are you?

   -> update the file and push to the server.

3. Person2 : branch
   filename : greeting.txt
   content : Person2: good Evening, Hope you are doing good.
   -> update the file and push to the server.

4. Person1 create a pull and merge change to main branch.
   in Main branch 
   filename : greeting.txt
   previous content : good morning.
   new content : Person1: good morning, How are you?


5. Person2 create pull request and try to merge the change to the main.
   -> new content :  Person2: good Evening, Hope you are doing good

6. Resolve merge conflict merge push the changes.

################## Steps to reproduce merge conflict scenario ################
Pre-requisite:
1. push all current changes to your branch
   (git status, git add, git commit, git push)
   -> revert your local changes.
   -> git checkout filename (Revert specific file)
   -> git checkout . (Revert all changes)

2. switch to main branch or any other branch
   -> git checkout main
   -> git checkout branchName

3. git pull : Update all code changes.
   -> git pull

4. current active Branch should be main.
   -> git branch
   -> main branch should show in green color.
